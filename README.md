# Restaurant Finder 🍔🔍

A microservices-based system (Spring Boot & Spring Cloud) focused on finding restaurants and generating intelligent recommendations powered by Artificial Intelligence.

## 🏗️ Architecture

The project is composed of 4 main microservices and a messaging infrastructure:

- **Eureka Server (`8761`)**: Service Discovery, responsible for registering and locating all microservices.
- **Restaurant Service (`8081`)**: API for managing the restaurant catalog.
- **User Service (`8082`)**: API for managing users and their preferences.
- **Recommendation Service (`8083`)**: API that consumes user preferences and available restaurants, utilizing **Spring AI** to return the best restaurant options with explanations generated by artificial intelligence.
- **RabbitMQ (`5672` / `15672`)**: Message Broker for asynchronous communication.

## 🚀 Technologies Used

- **Java 17+**
- **Spring Boot 3**
- **Spring Cloud** (Netflix Eureka)
- **Spring AI**
- **RabbitMQ**
- **Docker** & **Docker Compose**
- **Gradle**

## ⚙️ How to Run

### Prerequisites
- [Docker](https://www.docker.com/) installed.
- [Java 17+](https://adoptium.net/) installed.
- API Token for your chosen AI Provider.

### 🤖 AI Provider Configuration

This project was built using **Spring AI**, which means you can configure it to use any AI provider you prefer (such as Google Gemini, OpenAI, Anthropic, etc.). 
- **To use the default setup (tested with Google Gemini):** You just need to provide your `GEMINI_API_KEY` (from Google AI Studio) when running the Recommendation Service.
- **To use a different provider:** Change the AI starter dependency in `recommendation-service/build.gradle` and update the respective AI properties in `recommendation-service/src/main/resources/application.properties`.

### Running with Docker Compose (Messaging Infrastructure)

The project is configured to run RabbitMQ isolated via Docker, ensuring lower local resource consumption and bypassing possible Docker Hub download blocks in restricted network environments (like universities).
